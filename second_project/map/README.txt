This folder must contain the map files generated by slam_toolbox after running Task 1.

Steps to generate and save the map:
1. Start the mapping launch and play the bag:
     Terminal 1: ros2 launch second_project mapping.launch.py use_sim_time:=true
     Terminal 2: ros2 bag play <path_to_bag> --clock

2. Once the map looks good in RViz, save it using map_saver_cli:
     ros2 run nav2_map_server map_saver_cli -f ~/ros2_ws/src/second_project/map/map

   This creates:
     map.pgm  – occupancy grid image (black = occupied, white = free)
     map.yaml – metadata (resolution, origin, thresholds)

3. Alternatively, use the slam_toolbox serialization service to save the full
   pose graph for later localization:
     ros2 service call /slam_toolbox/save_map slam_toolbox/srv/SaveMap \
       "name: {data: 'map'}"

4. Update the Stage world file (worlds/second_project.world):
     - Set the 'size' field to match your map's real-world dimensions
       (pixels_width * resolution) x (pixels_height * resolution)
     - Set the robot starting 'pose' to a free location in the map

Expected files after mapping:
  map.pgm   (mandatory)
  map.yaml  (mandatory)
